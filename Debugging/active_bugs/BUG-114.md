# BUG-114: Combat Lab — Projectile test targets remain stationary (regression)

## Description
PROJ360-002 (slow linear) and PROJ360-003 (fast linear) target ships remain stationary during visual and headless runs. Both targets have engines and "test_straight_line" AI strategy, but the AI controller's `update()` early-returns before executing movement behavior because `find_target()` returns None.

The scenario setup (`templates.py`) only sets `attacker.current_target = target` — the target ship's target is never set. The AI controller requires a non-None target (or formation membership) to proceed past the early return to behavior execution.

This is a regression: damage_dealt was 250 (target moving) through February 6, but dropped to 0 (stationary) on March 27.

**Key files:**
- `game/ai/controller.py` — `update()` early return when no target found
- `simulation_tests/scenarios/templates.py` — setup only sets attacker's target (line ~152)
- `simulation_tests/scenarios/projectile_scenarios.py` — PROJ360-002 and PROJ360-003 definitions
- `simulation_tests/data/ships/Test_Target_Linear_Slow.json` — has engine (thrust=50), ai_strategy "test_straight_line"
- `simulation_tests/data/ships/Test_Target_Linear_Fast.json` — has engine (thrust=1500), ai_strategy "test_straight_line"
