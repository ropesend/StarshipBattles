# BUG-111: SeekerPointDefenseNoneScenario Crashes During Batch Run — Missing `attacker` Attribute

## Description
During a Combat Lab batch run, `SeekerPointDefenseNoneScenario` crashes with `AttributeError: 'SeekerPointDefenseNoneScenario' object has no attribute 'attacker'`. The scenario has `skip_test = True`, which causes `setup()` to return early without initializing `self.attacker`. When the batch runner subsequently calls `scenario.update(engine)`, the `update()` method in `StaticTargetScenario` (templates.py:161) tries to access `self.attacker`, causing the crash.

The root cause is that scenarios with `skip_test = True` still get their `update()` method called by the batch runner, but `update()` doesn't guard against uninitialized attributes from a skipped setup.
