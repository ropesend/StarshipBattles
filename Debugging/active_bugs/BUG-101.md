# BUG-101: Fleet Info Panel Shows Raw Enum Names for MOVE_TO_FLEET and JOIN_FLEET Orders

## Description
The lower-right fleet info panel on the strategy map displays orders like "MOVE_TO_FLEET" and "JOIN_FLEET" as raw enum names, without showing the target fleet ID. The Orders dialog window correctly formats these as "INTERCEPT Fleet 10000" and "JOIN Fleet 10000".

Fleet info panel showing raw enum names without targets:
[![Fleet info panel showing MOVE_TO_FLEET and JOIN_FLEET without target IDs](../../Tools/qa_observer/session_data/20260323_143412/images/bug_capture_144854.png)](../../Tools/qa_observer/session_data/20260323_143412/images/bug_capture_144854.png)

### Root Cause
`strategy_detail_fmt.py:_format_orders()` (lines ~278-328) doesn't handle `MOVE_TO_FLEET` and `JOIN_FLEET` order types. They fall through to the generic `else` clause at line ~326 which renders `order.type.name`.

The correct formatting logic already exists in `fleet_orders_window.py:_get_order_description()` (lines ~185-220), which uses `is_fleet(order.target)` to extract the target fleet ID and formats as "INTERCEPT Fleet {id}" / "JOIN Fleet {id}".

### Fix Reference
Add MOVE_TO_FLEET and JOIN_FLEET cases to `_format_orders()` in `strategy_detail_fmt.py`, matching the pattern from `fleet_orders_window.py`:
```python
elif order.type == OrderType.MOVE_TO_FLEET:
    f_id = order.target.id if is_fleet(order.target) else "?"
    text += f" {i+1}. Intercept Fleet {f_id}<br>"
elif order.type == OrderType.JOIN_FLEET:
    f_id = order.target.id if is_fleet(order.target) else "?"
    text += f" {i+1}. Join Fleet {f_id}<br>"
```
