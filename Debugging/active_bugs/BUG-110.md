# BUG-110: Combat Lab Visual Run — No Transition to Battle Screen

## Description
When launching a visual run from the Combat Lab Test Viewer (e.g., BEAMWEAPON-001), clicking the run button does not transition to the battle screen. The user remains on the Test Viewer with the only visible change being a "paused 1X" indicator at the top. It is possible a single frame of the battle view flashes before reverting, but no persistent visual change occurs.

The combat_lab.log confirms the scenario is fully instantiated and set up successfully — ships are loaded, registered with the battle engine, and setup completes without errors. The disconnect appears to be between `test_executor.run_visual()` completing scenario setup and `_switch_to_battle()` actually transitioning the active scene to the battle screen. The game state change to `GameState.BATTLE` either fails silently, is immediately overridden, or the battle scene is rendered behind/beneath the test viewer.
