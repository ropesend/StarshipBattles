# BUG-104: Event log window column reorder arrows not wired up

## Description
The Event Log window uses `VirtualTable` with `TableColumnManager` and `TableHeader`, which render column reorder arrows (< >) in the header. However, clicking the arrows does nothing because the `EventLogWindow` never calls `check_header_presses()` in its update loop.

All three other VirtualTable-based windows (EmpireBuildQueueWindow, PlanetListWindow, FleetReportWindow) correctly wire up column reordering by calling `virtual_table.check_header_presses()` and delegating to `column_manager.swap_column()`. The EventLogWindow is the only one missing this wiring.

### Fix Pattern
Add the standard column swap handling to `EventLogWindow.update()`, matching the pattern used by the other three windows:
```python
header_result = self.virtual_table.check_header_presses()
if header_result.get('swap_column'):
    col, direction = header_result['swap_column']
    self.column_manager.swap_column(col['id'], direction)
    self.virtual_table.rebuild_headers()
    self.virtual_table.rebuild_row_pool()
    self.refresh_list()
```
