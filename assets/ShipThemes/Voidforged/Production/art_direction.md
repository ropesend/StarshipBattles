# Voidforged Ship Theme

Voidforged is a sixth independent ship theme for Starship Battles. It should sit beside the existing five themes without modifying them.

## Visual Identity

- Matte black and dark gunmetal hulls.
- Violet singularity cores and engine glow.
- Sparse cold cyan edge lights.
- Blade-like silhouettes with slight asymmetry.
- Top-down orthographic game-token framing.
- Clean transparent background for skins.
- High contrast readable hull edges at small in-game sizes.

## Asset Targets

- Skins: `2048x2048` PNG with alpha, centered ship, generous padding.
- Portraits: `1024x1024` JPG, three-quarter concept-art style for UI thumbnails.
- Required class coverage: 19 assets, matching `theme.json`.

## Prompt Template

Use case: stylized-concept
Asset type: top-down 2D game ship sprite
Primary request: Create a Voidforged `<SHIP_CLASS>` starship.
Subject: A distinct top-down orthographic spaceship for the `<SHIP_CLASS>` role.
Style/medium: polished sci-fi game asset, detailed hard-surface concept art, token-ready sprite.
Composition/framing: centered, top-down orthographic view, nose pointed upward, full ship visible, generous padding.
Lighting/mood: soft overhead lighting, readable silhouette, violet core glow, cold cyan edge lights.
Color palette: matte black, dark gunmetal, violet plasma, small cyan accents.
Materials/textures: layered armored plating, obsidian ceramic panels, exposed reactor channels, subtle battle wear.
Constraints: transparent or perfectly flat removable chroma-key background, no cast shadow, no text, no watermark.
Avoid: existing Star Trek faction shapes, cream Federation hulls, green Klingon glow, red Romulan glow, cyan-only Thoralian look.

## Class Shape Notes

- Escort: narrow fast dart with one bright aft singularity.
- Frigate: slim armored spine with short blade fins.
- Destroyer: compact forward wedge with paired weapon booms.
- Light Cruiser: longer knife-like cruiser, still agile.
- Cruiser: balanced central hull with swept asymmetric wings.
- Heavy Cruiser: thicker armor blocks and larger violet reactor.
- Battle Cruiser: long predatory blade with pronounced side weapons.
- Battleship: broad layered armor, heavy prow, multiple engine cores.
- Dreadnought: massive central spine, fortress-like aft section.
- Superdreadnought: largest silhouette, cathedral-like dark armor layers.
- Monitor: wide defensive platform with circular singularity core.
- Fighters: compact sharp silhouettes, increasing mass by size.
- Satellites: radial or ring structures, not ship-shaped, increasing complexity by size.
