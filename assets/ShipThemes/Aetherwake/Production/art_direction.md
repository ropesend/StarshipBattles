# Aetherwake Ship Theme Art Direction

## Brief

Aetherwake is an original orbital fleet inspired by the attached reference image's massive near-planet carrier silhouette, tiered command structures, dark hard-surface armor, and warm running lights. The reference image is used for massing, surface density, orbital scale, and mood only; the final fleet should not copy a specific ship.

## Reference Inputs

- Conversation attachment, user-provided orbital capital ship image: used as massing inspiration, surface material reference, and mood reference.

## Palette

- Primary hull: graphite blue-black, near `#101820`.
- Secondary armor: cold glacier gray, near `#b8c7ce`, used as broad inset plates and prow caps.
- Trim: oxidized copper, near `#b8763a`, used sparingly along vents and panel lips.
- Glow: reactor cyan, near `#39e6ff`, with small amber running lights near `#ffad66`.
- Avoid: dominant purple, sand/beige, pure black silhouettes, bright green in the subject, Federation/Klingon/Romulan color cues, and Voidforged-style all-black occult shapes.

## Theme Lock

Palette: graphite blue-black primary hull, cold glacier-gray armor plates, sparse oxidized-copper trim, reactor-cyan glow trenches and engines, tiny amber running lights. Hull material: dense matte naval armor with beveled layered plates, inset carrier-deck slabs, recessed maintenance panels, and fine white serial-free stencil-like panel marks that are abstract geometry only, not readable text. Silhouette motifs: wedge or crescent prow, broad outrigger hangar wings, stepped dorsal command island or sensor spine, negative-space engine vents, and tiered armored shoulders. Material details: cyan recessed reactor seams, amber pinlight rows, copper vent lips, glacier-gray prow caps, and dark radiator grilles. Glow placement: cyan only in aft engine clusters, inner negative-space vents, and narrow longitudinal hull trenches; amber only as tiny window-like running lights along side edges. Weapon visibility: no visible turrets, cannon barrels, missile racks, torpedo tubes, exposed gun pods, or obvious external weapons; combat capability is implied only by flush armor seams, recessed bay doors, sensor slits, hardpoint panel lines, or concealed ports integrated into the hull.

## Skin Prompt Template

Use case: stylized-concept
Asset type: top-down 2D game ship sprite for Starship Battles
Primary request: Create a model-generated Aetherwake <CLASS> starship.
Input image: use the attached orbital capital ship image as inspiration for massing, surface language, lighting mood, and naval carrier scale; do not copy the exact ship.
Subject: <class-specific silhouette>.
Style/medium: polished sci-fi game asset, detailed hard-surface concept art, token-ready sprite.
Composition/framing: centered, top-down orthographic view, nose pointed upward, full object visible, generous padding, single object only.
Background: perfectly flat solid #00ff00 chroma-key background for background removal.
Constraints: no shadow, no text, no watermark, no UI frame, no multiple ships, do not use #00ff00 in the subject.
Weapon visibility: no visible turrets, cannon barrels, missile racks, torpedo tubes, exposed gun pods, or obvious external weapons. Weaponry must be implied by flush armor seams, recessed bay doors, sensor slits, hardpoint panel lines, or concealed ports integrated into the hull.
Theme consistency: include the Theme Lock block verbatim. Vary only class size, role proportions, wing span, engine count, and platform geometry.
