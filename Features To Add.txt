Resource Harvesting
- Each planetary resource should have it's own harvesting component.
- The component should harvest an amount that is based on the quality of the resource on the planet * the base rate of the component.
- more modifyers will be added later
- The component will reduce the total amount of the resource on the planet by the amount it produces each turn.  
- Each planetary resource also needs a storage component - this will be used to store the resources
- For now we will use a "magical" distribution system that makes all of the stored resource available wherever it is needed in the empire.
- The resource system should be handled generically similar to the resource system for ships, it should be possible to mod in additional resources by editing the .json files.
- if excess resource is produced then it should be stored in the storage component, if the storage component is full then the excess resource should be lost.  It should simply be a global pool of resources for the empire.
- All build queues should be edited to use up resources, currently they build everything in 1 day for free, we should change this so that they can build at a limited rate, say may 5000 units of each resource per turn.  Anything that requires more than that will have to wait until the next turn, and the build queue should show how much of each resource is needed for the next turn.   If an item is finished during a turn it should be removed from the build queue, and the remaining resourse can be used for the next item in the build queue.  Some items may require a lot more of one resource than another, The resource use should be proportional lets say a ship is 100000 for one resource and 10000 for another resource, then each turn it should consume 10 times as much of the first resource as the second resource.
- The building should be very granular, it should be processed in 100 tick increments, so that it is possible to have fractional resource usage per turn.  If a ship is created then it could be launched into space at any point during the turn.
- All ships should have a maintenance cost, this should be deducted from the empire's resources each turn, it should be 5% of the build cost of the ship.  Complexes should also have a maintenance cost, this should be deducted from the empire's resources each turn, it should be 5% of the build cost of the complex.
