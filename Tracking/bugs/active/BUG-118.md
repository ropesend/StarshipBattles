# BUG-118: Race Setup — "Randomize All" doesn't refresh Summary tab left-column labels

## Description
After clicking the "Randomize All" button on the Summary tab of the Species
Setup screen, the underlying race configuration is randomized correctly (data
is visible on the Identity / Visuals / Environment / Aptitudes tabs and in the
Summary tab's right column for Environment / Aptitudes), but the Summary tab's
**left column** — Faction, Species, Government, Physical, Society — continues
to show "—".

Switching to any other tab and back to Summary forces the labels to populate.

This is a defect in the FEAT-12 implementation (currently Awaiting
Confirmation). FEAT-12 itself otherwise works.

## Root Cause
`RaceSetupController.populate_ui_from_config()` in
`game/ui/screens/race_setup/controller.py:180-219`:

- Lines 189-200 update the `race_config` reference on every panel **including**
  `screen._summary_panel`.
- Lines 206-219 call `panel.set_from_config()` on every panel **except** the
  summary panel.
- The summary panel uses a `refresh()` method (different name) and is not
  invoked on this path.

Tab-switching works because `RaceSetupScreen._show_step()` (line 310-311) calls
`_refresh_summary()` (lines 340-345) which explicitly invokes
`self._summary_panel.refresh()`.

## Fix
At the end of `populate_ui_from_config()` (after line 219), add:

```python
if screen._summary_panel:
    screen._summary_panel.refresh()
```

This ensures the Summary tab's left-column labels stay in sync with
`race_config` whenever the controller mutates it programmatically — covering
`randomize_all()` and any future bulk-update entry points.
