# BUG-119: Plasma Storm sector effects not displayed (storm hex coordinate-frame mismatch)

## Description
A Plasma Storm declares two `scope: "sector"` abilities in `data/storms.json`
(`ShieldModifier` 0.7x and `EnvironmentalDamage` 0.5/turn plasma). The storm's
hover tooltip says *"Effects appear in the Sector Effects panel."* When the
user clicks on a hex occupied by the storm, the Sector panel shows the storm
reference and "Local Radiation Analysis" — but **no Sector Effects entries**
are listed.

The same problem affects every storm type (Ion Storm, Plasma Storm, Magnetic
Storm, Radiation Storm, Gravimetric Storm) since they all share the same
sector-scope ability registration path.

## Root Cause — Coordinate-frame mismatch
- `Storm.location` and `Storm.occupied_hexes` are **local** system coordinates
  (`game/strategy/data/storm.py:50-58`: "Returns all hexes occupied by this
  storm in local system coordinates.").
- `StormAbilitySource.affects_hex(hex_coord)` does a raw
  `hex_coord in self.storm.occupied_hexes`
  (`game/strategy/services/ability_sources/storm.py:40-49`).
- The Sector panel passes the **global** hex from the strategy map view
  (sector header in screenshot reads `[1969, 817]` — well outside the
  ~101-diameter local system frame).
- Result: every `affects_hex` call returns False; the storm never yields
  abilities; the collector returns empty; the UI never renders the Sector
  Effects group.

The matching planet path translates correctly via `_planet_global_hex` in
`game/strategy/services/ability_iterator.py:162-175` — the storm provider has
no equivalent translation.

## Suggested Fix
Add a global→local (or local→global) translation in `_storm_provider` /
`StormAbilitySource.affects_hex`, mirroring `_planet_global_hex`. Easiest:
have `_storm_provider` translate `hex_coord` from global to system-local
before constructing/querying adapters, or compute the storm's global
occupied hexes (`system_loc + storm.location + offset`) and compare in global
frame.

Verify the fix with the existing storm types in `data/storms.json`. The
Sector Effects panel should show `ShieldModifier x0.7` and
`EnvironmentalDamage 0.5 plasma/turn` (or formatted equivalents) on each of
the storm's hexes.
