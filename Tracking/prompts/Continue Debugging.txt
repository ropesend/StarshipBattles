   any fix. Read relevant `docs/` files (`docs/01_ARCHITECTURE.md`, `docs/02_PATTERNS.md`,

   * Select highest priority bug.
   * LOAD ticket file (e.g., Tracking/bugs/active/BUG-XX.md).
   * EXECUTE full cycle including Phase 2.5 integrity check:
     Phase 0 (Context) -> Phase 1 (Red) -> Phase 2 (Green) -> Phase 2.5 (Integrity Check) -> Phase 3 (Doc) -> Phase 4 (Status).

   * DO NOT wait for input - proceed to next bug.

AUTONOMOUS MODE: Do not stop between bugs. Only stop for context limit or empty queue.
