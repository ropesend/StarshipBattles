# BUG-100: Planet List Window Column Reorder Arrows Do Not Swap Columns

## Description
Clicking the left/right arrows on column headers in the Planet List Window does not reorder columns. The click is detected and the UI rebuilds, but `column_manager.swap_column()` is never called — the actual swap is missing.

The Build Queue Window (`empire_build_queue_window.py:459-464`) and Fleet Report Window (`fleet_report_window.py:306-308`) both implement this correctly. The Planet List is the only screen with the bug.

### Root Cause
`planet_list_window.py:326-330` — when `header_result.get('swap_column')` is truthy, the code rebuilds headers and row pool but never calls `self.column_manager.swap_column(col_dict['id'], direction)` before rebuilding.

### Fix Reference
Add the missing `swap_column()` call before the rebuild, matching the pattern in `empire_build_queue_window.py:461`:
```python
if header_result.get('swap_column'):
    col_dict, direction = header_result.get('swap_column')
    self.column_manager.swap_column(col_dict['id'], direction)  # <-- missing line
    self.virtual_table.rebuild_headers()
    self.virtual_table.rebuild_row_pool()
    self.refresh_list()
```
