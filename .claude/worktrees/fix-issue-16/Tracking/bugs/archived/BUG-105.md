# BUG-105: Fleet orders dialog too narrow — down arrow and X buttons hidden until resized

## Description
When the fleet orders dialog opens, only the up-arrow buttons are visible next to each order. The down-arrow and X (remove) buttons are clipped off the right edge of the dialog. They appear after clicking an arrow (which triggers a layout rebuild) or after manually resizing the window wider. The dialog's default width needs to be increased to accommodate all three buttons (up, down, X) per order row.

## Investigation Report

### Root Cause
- Window opened at **400px width** (hardcoded at `strategy_window_manager.py:305`)
- Container subtracts 32px for scrollbar/padding → **368px usable**
- Button layout requires **410px** (delete button at X=380, width 30)
- Result: down-arrow and X buttons clipped off right edge

## Hypothesis Log

### Hypothesis 1: Hardcoded window width too narrow for button layout - CONFIRMED
**Theory:** The 400px initial window width cannot accommodate buttons that extend to X=410.
**Evidence For:** Layout math proves 410px needed, only 368px available. Screenshots confirm clipping.
**Evidence Against:** None.
**Test:** Increase width to 480px and make buttons relative to container width.
**Result:** All buttons visible; positions adapt to window width. 1807 UI tests pass.
