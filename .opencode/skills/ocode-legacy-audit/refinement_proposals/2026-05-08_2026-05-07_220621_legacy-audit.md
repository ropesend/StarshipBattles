## Save-migration scanner false-negative pattern

The audit's deterministic `save_migration_code` scanner found 0 findings, but agent review surfaced **4** save-migration code blocks (LEG-03-008, LEG-03-017, LEG-03-018, LEG-04-005). They slipped through because the deterministic scanner looks for the literal word "migration" in the logic, while the actual code uses comments like:

- `# Legacy toggle migration.`
- `# Backward compat: old format was just {'active': bool}`
- `# legacy `component_damage` key in old saves is silently ignored`
- `# Legacy 2-side format` (key emit at lines 265-269; fallback read at 290-300)

**Suggested scanner extension** for `Tools/legacy_audit/`:

- Add a heuristic "save-migration shape detector": flag code blocks that (a) sit inside a `from_dict` or `_load_*` method, (b) gate on a shape-check (`if 'X' not in data` / `if isinstance(data, dict) and 'side_0' in data`), AND (c) carry a comment containing any of `legacy|backward.compat|old.format|disposable`. The `# legacy` / `# Backward compat` half is already in deterministic scanner range; the structural-position half (inside a deserializer) is what the agent path catches today.
- Alternatively: tag every `from_dict` / deserializer for the **agent** review pass with an explicit prompt to look for shape-check legacy branches, since these will always read as "deprecation marker" or "additional indicator" to the deterministic scanner.

**Test against this run:** all 4 save-migration findings landed in PROJ-386 with `[banned by CLAUDE.md Rule 3]` callouts. They were policy-non-negotiable, but the scanner didn't surface them. Closing this scanner gap should bump the value of the deterministic phase.

## Severity-rebalance proposal

Across the 11 projects, the most common shape is "MINOR — `# legacy` comment on a non-trivial fallback branch that exists for tests that don't inject deps." Eight findings fit this pattern (LEG-03-004 through LEG-03-007 plus LEG-02-006, LEG-04-004, etc.). They cluster naturally as "test-injection legacy fallbacks" — the audit reported them as separate MINORs spread across shards.

**Suggested taxonomy add:** introduce a category `test_injection_fallback` distinct from generic `deprecation_marker`. The shape-detector is "production code path that is legacy ONLY because tests don't inject the canonical dep." This would let the bundler group these naturally without the user having to spot the pattern.
