# BUG-107: Game crashes on turn advance after loading a save — ShipInstance missing registries

## Description
Loading a saved game and advancing a turn causes a crash:
```
ValueError: ShipInstance requires registries for stats calculation. Use ShipInstance.create() or from_dict() with registries parameter, or set ship._registries after construction.
```

The crash occurs in `resource_management_engine.py` when calculating per-turn ship maintenance costs during turn processing.

[![Treasury/resource overview before crash](../../Tools/qa_observer/session_data/20260324_163416/images/bug_capture_165803.png)](../../Tools/qa_observer/session_data/20260324_163416/images/bug_capture_165803.png)
*Empire Overview / Treasury screen shown just before the crash — user was checking resource numbers before advancing the turn.*

### Root Cause
`GameSession.from_dict()` creates registries (`session._registries`) but does not pass them when calling `Empire.from_dict()`. The `registries=None` propagates down the entire deserialization chain:

```
GameSession.from_dict()
  → session._registries = GameRegistries(...)   # ✓ Created
  → Empire.from_dict(emp_data, galaxy=session.galaxy)  # ✗ Missing registries parameter
    → Fleet.from_dict(fleet_data, registries=None)
      → ShipInstance.from_dict(ship_data, registries=None)
        → instance._registries = None  # ✗ Ships have no registries
```

All loaded ships end up with `_registries = None`, causing the crash on first stats calculation.

### Crash Trace
```
turn_engine.process_turn()
  → _process_tick()
    → resource_engine.process_per_turn_consumption()
      → ship.get_all_resource_costs_per_turn()
        → ship._resource_mgr.get_all_resource_costs_per_turn()
          → ship.get_calculated_stats()
            → raises ValueError (registries is None)
```

### Key Code Locations
- `game/strategy/engine/game_session.py` ~line 322 — `Empire.from_dict()` call missing `registries=session._registries`
- `game/strategy/data/empire.py` ~line 224 — `from_dict()` accepts `registries` parameter, passes to Fleet
- `game/strategy/data/fleet.py` ~line 305 — `from_dict()` accepts `registries` parameter, passes to ShipInstance
- `game/strategy/data/ship_instance.py` ~line 668 — `from_dict()` sets `_registries` from parameter
- `game/strategy/engine/resource_management_engine.py` line 91 — crash site

### Fix
Pass `registries=session._registries` in the `Empire.from_dict()` call in `GameSession.from_dict()`.

### Secondary Issue
`Fleet.from_dict()` also extracts `component_registry` from registries for `FleetCapabilityCalculator`. When registries is None, this could cause additional issues when fleet capabilities are queried.
