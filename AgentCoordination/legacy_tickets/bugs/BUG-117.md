# BUG-117: Ship details "Main Systems" shows broken "Max Egy: --" / "Egy Gen: --"

## Description
The "Main Systems" column on the ship details / design stats panel displays two
energy rows — `Max Egy: --` and `Egy Gen: --` — that never populate. The same
information already appears (correctly) in the Combat Resources section as
`Energy Capacity` and `Energy Max Usage`.

Reproduced in QA Session 20260427_151244 at 15:18:

[![Main Systems showing Max Egy: -- and Egy Gen: --](../../../tools/qa_observer/session_data/20260427_151244/images/bug_capture_151810.png)](../../../tools/qa_observer/session_data/20260427_151244/images/bug_capture_151810.png)

## Code Investigation
- Section defined in `data/stats_sections.json:26-36`:
  - `{"id": "max_energy", "label": "Max Egy"}`
  - `{"id": "energy_gen", "label": "Egy Gen", "key": "energy_gen_rate", "formatter": "fmt_decimal", "unit": "/s"}`
- `StatDefinition.get_value` calls `getattr(ship, attr_key, 0)`
  (`game/ui/screens/builder/stat_definitions.py:34-41`).
- Neither `max_energy` nor `energy_gen_rate` are direct attributes on `Ship` —
  energy capacity is accessed via `ship.resources.get_max_value("energy")`
  (see `game/simulation/entities/ship_serialization.py:118`).
- Combat Resources section already exposes the same data correctly via the
  `get_resource_storage(ship, "energy")` getter.

## Fix
Remove the `max_energy` and `energy_gen` items from the `main` section in
`data/stats_sections.json`. They are stale duplicates from a previous iteration
of the stats layout and are fully covered by the existing Combat Resources rows
(Energy Capacity / Energy Max Usage).

After removing the rows, verify no other code references the `max_energy` /
`energy_gen` ids in the Main Systems section context.
