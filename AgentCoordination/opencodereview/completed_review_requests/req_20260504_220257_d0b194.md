## What to look for

### Primary concern: Behavioral parity

For 3 randomly-picked classes (1 from PROJ-329B, 2 from PROJ-329C), verify the refactored code does EXACTLY what the original did. Trace:

### Secondary concerns

1. **Pattern §33 conformance** — cheap state + delegates BEFORE bypass guard, explicit `ui_builder` parameter, default builder, Null/Mock fixture pair using `tests/fixtures/ui_builder_protocol.py:UiBuilder`. Pick one class per project and confirm the recipe is fully applied.
