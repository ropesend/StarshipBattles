Here are are a few new abilities, components and complexes that I want added to the game, none of the complexes start out constructed.

Expand Shied ShieldProjection to have fleet, Sector Player, Sector Allied, System Palyer, System Allied possible scopes
Create two componenets and starter complexes: 
Sector Shield Projector - projects 100 shield points to all playuer and allied vessels in the sector
Ssytem Shield Projector - projects 50 shield points to all player and allied vessels in the sector

Add Shield Modifyer Ability - simple value from 0 to infinity, all shields within the scope are multiplied by the value, so a 1.50 would change a ship with a normal 100pts shielding to 150pts
Scopes should be: Self, Fleet, Sector (allied or player or enemy), system (allied or player or enemy)
Create these components:
System Shield Supressor: 0.75 value, system enemy scope - used to reduce the effectivness of enemy shield in system
System Shield Booster: 1.25 value system allies scope - used to boost player and allied vessels shields in system
Sector versions of both above - 0.50, and 1.50
Fleet Versions of both - 0.95, and 1.05
Create starter complexes for the system and sector versions (4 total complexes) - they do not start out constructed.

Add Damage Modifyer Ability - similar to shield modifyer - 0 to infinitty, same scopes as Shiled modifyer
Create 6 components similar to the Shield mopdifyers, same values and scopes
Create 4 starter complexes  similar to above

Add Planet Modifyer abililities: - All require an interface to set the levels, Gavity and Radiation are not permanent, Water is permanent - similar to atmosphere modifyer.  Water takes time similar to atmosphere to change system, Gravity and Radiation are near instant I want a timer system like there is for the system sterllar stabilizer and warp field stabilizer.
Gavity Modifyer - provides a different level of gavity for the planet, can be set for the species on the planet, facility does not permanently change the gravity, if it is destroyed/removed then the gravity reverts to the original gravity
Water Modifyer - provides a different level of water for the planet, this is similar to the atmospheric modifyer but for water, it permanentlky alters the amount of water on the planet.
Radiation Shiled - provides protection from radiation and reduces its effects on the planet, this is similar to the gavity modifyer in that it is not permanent and can be reversed.
I want a component for each of the planet modifyer abilities, and a starter complex for each of them - 3 starter complexes.
