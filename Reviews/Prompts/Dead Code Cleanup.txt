## Review Focus Areas

### Agent 1: Trivial Delete Verifier (Categories A, B, F, G)
- **Verify zero dependencies** for each file in Categories A, B, G
- Run import/reference analysis to confirm nothing imports these
- For __pycache__ (Cat F): count exact .pyc files and total size
- Produce a definitive "safe to delete" list with zero-risk confidence
- Check for any README or documentation that references these files
- **Output:** Deletion manifest with file paths and sizes

### Agent 2: test_framework/ Dependency Analyzer (Category C)
- Deep analysis of EVERY import from `test_framework/` in game code
- Map which test_framework classes/functions are actually used vs available
- Analyze `simulation_tests/` to determine if equivalent functionality exists
- Compare TestRunner vs simulation_tests runner capabilities
- Compare TestRegistry vs simulation_tests scenario registration
- Compare BattleStateCapture vs any simulation_tests equivalent
- Determine: can Test Lab UI be migrated to simulation_tests, or does test_framework serve a unique interactive purpose?
- **Output:** Migration feasibility report with: "can replace" / "needs new code" / "unique functionality" per test_framework module

### Agent 3: Tools/ and scripts/ Audit (Categories D, E)
- For EACH file in Tools/ and scripts/:
  - Check if imported by any game/ or test/ code
  - Check git log for last modification date
  - Read the file to understand its purpose
  - Categorize as: "active tool" / "one-time script (completed)" / "verification utility" / "unknown"
- Special attention to `Tools/formation_editor.py` — active dependency from `game/app.py`
- Propose final organization: what stays, what moves, what gets deleted
- **Output:** File-by-file disposition table

### Agent 4: Unused Import & Unreachable Code Scanner
- Scan ALL game/ files for:
  - Unused imports (imported but never referenced in the file)
  - Unreachable code after return/raise/break/continue
  - Functions/methods defined but never called (within the file AND across the codebase)
  - Classes defined but never instantiated or subclassed
  - Variables assigned but never read
- Exclude test files (they naturally have different patterns)
- Exclude `__init__.py` re-exports (intentional public API)
- **Output:** File-by-file list of unused items with confidence levels

### Agent 5: Misplaced File & Directory Structure Auditor (Category H)
- Audit the overall directory structure for:
  - Files in wrong directories (like `Tools/formation_editor.py` imported by game code)
  - Oddly named directories (`tests/refactor/` — should be `tests/regression/`?)
  - Empty or near-empty directories
  - The tkinter_utils.py situation: audit all 4 consumers, determine if tkinter is actually needed or if alternatives exist
  - `game/ui/panels/battle_panels.py` — verify BattlePanel has active subclasses
- **Output:** Relocation manifest with current path → proposed path

### Agent 6: Size & Impact Estimator
- Calculate total size of all confirmed dead code
- Estimate lines of code that would be removed
- Count files that would be removed
- Calculate reduction in `game/`, `Tools/`, `scripts/`, `test_framework/`, `docs/` directories
- Identify any configuration files (.json, .yaml, etc.) that reference dead code
- Check pytest configuration for any references to removed paths
- Check CI/CD configuration if any
- **Output:** Impact summary table with before/after metrics
