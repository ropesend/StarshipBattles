# Revise Project

**Protocol:** `Projects/protocols/06_revise_project.md`

Adopt the **Project Architect** persona.

## MANDATORY RULES

1. **DO NOT modify completed phases**: Add NEW phases sequentially.
2. **Document Reason**: Add entry to Decisions Log explaining the revision inspiration.
3. **Keep Focused**: Address specific feedback only; don't re-plan the whole project.
4. **Update Current State**: Reflect Revision status and next steps.

## Execution

1. **LOAD**: `Projects/active_projects/PROJ-[ID]/plan.md` (or archived equivalent).
2. **ASSESS**: determine scope (Minor Tweak / Enhancement / Rework).
3. **REACTIVATE**: move from archive if necessary.
4. **DOCUMENT**: log the decision.
5. **PLAN**: add new phases with specific tasks.
6. **VERIFY**: update checklists.
7. **PRESENT**: get user approval.

## Next Steps
- User approves revision plan.
- Use `/continue-project [ID]` to implement.
- `/audit-project [ID]` when complete.
