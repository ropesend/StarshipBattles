# Features — Feature Ticket Data

This directory stores feature ticket data. The protocols and workflows are in [`Tickets/README.md`](../Tickets/README.md).

## Directory Contents

| Path | Purpose |
|------|---------|
| `active_features/FEAT-XX.md` | Active feature tickets being worked on |
| `archived_features/FEAT-XX.md` | Completed and archived feature tickets |
| `feature_plan.md` | Feature queue dashboard with status tracking |
| `completed_features.md` | Index of completed features (date, summary, test case) |

## Quick Reference

- **Add a feature:** `/ticket-add feature <description>`
- **Implement a feature:** `/ticket-work feature 7` or `/ticket-next feature`
- **Batch implement:** `/ticket-continue feature`
- **Close a feature:** `/ticket-close feature 7`
- **Full documentation:** See [`Tickets/README.md`](../Tickets/README.md)
