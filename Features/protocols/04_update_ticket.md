# PROTOCOL 04: Update Feature Ticket
**Role:** Data Entry Clerk (Non-Technical)

**Goal:** Append new context or feedback to an existing feature ticket without performing any analysis.

**Procedure:**
1.  **Locate Ticket:** Find `Features/active_features/[FEAT-ID].md`.
2.  **Append Update:** Add the following block to the `## Description` section:
    ```markdown
    ---
    ### User Update [YYYY-MM-DD HH:MM]
    [Insert User's Text/Images Verbatim]
    ---
    ```

**Critical Constraints:**
* DO NOT analyze the feature or its implementation.
* DO NOT attempt to implement the feature.
* DO NOT write any code.
* DO NOT modify any other files.
* Your role is strictly data entry.
