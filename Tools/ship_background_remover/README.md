# Ship Background Remover

Removes black backgrounds from AI-generated ship artwork and centers the result on a square transparent canvas.

## Purpose

Ship images generated by AI art tools typically have solid black backgrounds. This tool converts them into transparent game-ready sprites by removing dark pixels below a configurable threshold, trimming the remaining content to its bounding box, and centering it on a standardized square canvas (default 2048x2048). Images larger than the target canvas are scaled down to fit.

## Requirements

- `Pillow` (PIL)

## Usage

```bash
python Tools/ship_background_remover/ship_background_remover.py --input <input_dir> --output <output_dir> [--threshold N] [--size N]
```

### Arguments

| Argument      | Required | Default | Description                                                    |
|---------------|----------|---------|----------------------------------------------------------------|
| `--input`     | Yes      |         | Directory containing source JPG/PNG ship images                |
| `--output`    | Yes      |         | Directory for output transparent PNGs (created if missing)     |
| `--threshold` | No       | 30      | RGB threshold for background removal (0-255). Pixels where all channels are at or below this value become transparent. |
| `--size`      | No       | 2048    | Target square canvas size in pixels                            |

### Processing Pipeline

1. **Background removal** -- pixels with R, G, and B all at or below the threshold are made fully transparent.
2. **Trim** -- transparent edges are cropped to the content bounding box.
3. **Center** -- the trimmed image is centered on a square canvas of the target size. If the content exceeds the canvas, it is scaled down proportionally using Lanczos resampling.

Supported input formats: `.png`, `.jpg`, `.jpeg`.

## Output

Transparent RGBA `.png` files in the output directory, one per input image. A summary count of successfully processed images is printed on completion.
