| 2026-04-18 | Phase 2: N2 default setpoint = 79 kPa (was 0) with tolerance = 20 kPa | Discovered during v1/v2 parity tests: an "Earth-like default race" with N2 setpoint=0 silently flunks every Earth-like planet (8σ N2 mismatch drags composite from ~1.0 to ~0.82). Other gases (CO2, CH4, NH3, SO2, etc.) keep setpoint=0 because they're toxic to Earth-derived life. |
| 2026-04-18 | Phase 2: `calculate_habitability_v2` epsilon = 1e-10 (matches v1) | Initial draft used 1e-4. Note: the property weakens for low-weight factors — a single per-gas factor (weight 0.15 / total 6.8) at 0 only drags composite to ~0.6 even at the floor. This is by design: with 17 factors and a smooth weighted-geometric-mean combiner, no single low-weight axis can fully tank the score. If a stronger "single critical missing gas → uninhabitable" property is wanted later, the path is to either (a) promote O2 to a scalar factor with weight 1.0+, or (b) change the combiner to use `min()` for axes flagged "critical". Out of Phase 2 scope. |
