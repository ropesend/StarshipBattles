PER-PROJECT WORKFLOW (apply this loop to each project, in order)
================================================================

For project PROJ-NNN, execute the following steps in sequence:

STEP A — IMPLEMENT
  Spawn a single subagent via the Agent tool with subagent_type "general-purpose" and the prompt:
    "Run /claude-proj-continue PROJ-NNN. Implement every phase listed in plan.md per the protocol at Projects/protocols/. Mark each phase Complete in plan.md and the phase checklist when its checkboxes are all checked. Do not commit. When all phases are done, report back with a list of files you modified and a one-line summary of behavioral changes (or 'annotations only' / 'test cleanup only' as applicable)."

  Wait for the subagent's reply. Do NOT spawn the next project's subagent until this step completes.

STEP B — CODEX AUDIT (mid-project review)
  Use the Skill tool to invoke:
    Skill: claude-consult
    args: --with codex --mode mid-project-review --slug audit-PROJ-NNN --question "Audit the just-completed PROJ-NNN. The implementer reported the file set <files>. The project's plan is at Projects/active_projects/PROJ-NNN/plan.md, decisions at decisions.md, manifest at manifest.md. Read the git diff against main for these files and report: (1) any deviation from the project's stated Goals or Scope in plan.md, (2) any introduced regression, layer-violation, or convention violation per docs/01-03, (3) any obvious missed callers / orphan symbols / stale comments left behind, (4) any test that was DELETED that should have been REWRITTEN instead. Be specific (file:line). Do NOT propose new features."

  The consult will write a response.md you can read.

STEP C — VERIFY CODEX FINDINGS
  For EACH finding in the consult response.md `## Findings` section:
    1. Open the cited file:line and confirm the finding is real (the code matches the description).
    2. Decide one of:
       - VERIFIED + IN-SCOPE: real issue, belongs in this project's scope per plan.md.
       - VERIFIED + OUT-OF-SCOPE: real issue but outside this project's stated Scope — log via /claude-di-log with link back to PROJ-NNN, then move on.
       - REJECTED: false positive (contrary evidence in the cited file, or audit-self-retraction pattern). Record rationale.

  Write your verification table to Projects/active_projects/PROJ-NNN/findings/audit_verification.md with rows: id | verdict | evidence | action.

STEP D — REMEDIATE (if verified in-scope findings exist)
  If any finding is VERIFIED + IN-SCOPE:
    1. Determine the next phase number N (= current max phase + 1).
    2. Create Projects/active_projects/PROJ-NNN/phase_N_checklist.md using the PHASE_TEMPLATE format from Projects/scripts/create_project.py:126-158. Title it "Phase N: Audit remediation (Codex consult <date>)". Add one task per verified finding.
    3. Update Projects/active_projects/PROJ-NNN/plan.md Quick Status table — add a new row for Phase N linking to the new checklist.
    4. Update Current State to point to Phase N.
    5. Spawn ANOTHER subagent (same skill: /claude-proj-continue PROJ-NNN) to execute the new phase.
    6. Wait for completion.
    7. Do NOT re-audit. One round only.

  Estimate first: if the remediation work would take more than ~15 minutes of LLM time (more than a few file edits + targeted tests), STOP and surface the situation to the user with a summary of findings. Do not unilaterally expand scope.

STEP E — VERIFY DONE
  Confirm all phases (incl. any added Phase N) are marked Complete in plan.md and their checklists. Then move to the next project in the order list above.
