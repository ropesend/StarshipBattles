## Step C: End-of-project codex audit

When ALL phases of a project are marked Complete, BEFORE moving to the next
project, dispatch a codex audit consult. The audit verifies the project's
closed findings actually closed in code and surfaces any side-effects or
regressions.

Pattern:

1. Compute a UTC timestamp: `(Get-Date).ToUniversalTime().ToString('yyyyMMddTHHmmssZ')`

2. Create the consult leaf:
       Projects-relative path:
       `AgentCoordination/Scratchpad/Consult/<TIMESTAMP>_proj-XXX-end-of-project-audit/`
       Create the directory.

3. Write `request.md` in that leaf. Use the consult/v1 schema. Reference
   shape from the bucket-B audit:
       `AgentCoordination/Scratchpad/Consult/20260519T014918Z_audit-bucket-B-engine-services/request.md`
   Required frontmatter:
       ```yaml
       ---
       protocol: consult/v1
       from: claude
       to: codex
       mode: planning
       allow_tests: false
       created_at_utc: <ISO 8601 UTC>
       repo_root: C:\Dev2\StarshipBattles
       consult_leaf: <absolute path to the leaf>
       complete: true
       ---
       ```

   Body should include:
   - `## Question` — explicit ask: "Audit PROJ-XXX end-of-project state.
     Read the project's plan.md + decisions.md + final phase_*_checklist.md
     + the actual diff (run `git log --oneline --grep='PROJ-XXX'` to find
     commits, then `git diff <first>^..<last>` for the range). Verify each
     closed finding actually closed in code. Flag any verified issues,
     regressions, cross-group collisions that materialized during
     execution, or new residue surfaced during the work."
   - `## Repo state` — output of `git status --short` and current branch
   - `## Constraints` — paste the canonical consult prompt block from
     `AgentCoordination/protocols/consult_prompt_block.md` verbatim (read
     the file and inline its contents).
   - `## Specific asks` — same schema-instruction block as the bucket
     audits (codex must write response.md atomically; provide per-finding
     verdicts: closed / partially-closed / not-closed; aim for ≤2000
     words).

4. Invoke codex via `Tools/agent_coordination/partner_invoke.py`. Pattern
   (run via Bash with run_in_background=true):
       ```python
       import json, sys
       from pathlib import Path
       REPO_ROOT = Path(r"C:\Dev2\StarshipBattles")
       LEAF = Path(r"<consult leaf absolute path>")
       REQUEST = LEAF / "request.md"
       RESPONSE = LEAF / "response.md"
       LOG = LEAF / "log.txt"
       sys.path.insert(0, str(REPO_ROOT / "Tools" / "agent_coordination"))
       import partner_invoke
       PROMPT = (
           f"Load the codex-starship-consult-respond skill. Process the "
           f"consult request at {REQUEST}. Honor the permission contract: "
           f"read-only by default; tests only if allow_tests=true (this "
           f"consult has allow_tests=false). Write your response.md "
           f"atomically (temp+rename) at {RESPONSE}. The full schema is in "
           f"the request body. Final ownership belongs to the initiator; "
           f"you advise, you do not implement."
       )
       result = partner_invoke.invoke_sync(
           "codex", PROMPT, log_path=LOG, repo_root=REPO_ROOT,
           response_file=RESPONSE, sandbox="workspace-write",
           timeout_sec=2400, model=None,
           expected_from="codex", expected_to="claude")
       print(json.dumps({
           "exit_status": result.exit_status,
           "error_kind": result.error_kind,
           "return_code": result.return_code,
           "partner_completed": result.partner_completed,
           "response_exists": RESPONSE.exists(),
           "response_bytes": RESPONSE.stat().st_size if RESPONSE.exists() else 0,
       }, indent=2))
       ```

5. Wait for the response.md to land. Read it carefully.
