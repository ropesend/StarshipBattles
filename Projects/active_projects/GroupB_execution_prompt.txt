dispatch a codex audit consult. The audit verifies the project's closed

**Consult location** (per protocol §10):

`Projects/active_projects/PROJ-XXX/consults/<UTC-ts>_end-of-project-audit/`

This is tracked per-project (visible across machines after push), not the
old gitignored Scratchpad location.

**Pattern**:

1. Discover repo root at runtime (per protocol §8) — no hardcoded paths.
2. Compute UTC timestamp; create the consult leaf under the project.
3. Write `request.md` using the consult/v1 schema (frontmatter shape per

remaining issues are explicitly out of scope per the project charter.
