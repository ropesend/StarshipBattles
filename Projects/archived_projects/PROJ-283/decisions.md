| 2026-04-18 | Phase 3: reproduction refund uses linear-in-rate math (not Python's `round(...)` integer steps) | The plan's table requires `0.005 → -5` refund (i.e. 2.5 steps × 2 = 5). Switched to `delta / step * refund_per_step` (continuous in rate), then rounded. Result: 2% → -2, 1% → -4, 0.5% → -5, anything below 0.5% clamps to floor and returns -5. Matches the user-confirmed table exactly. |
